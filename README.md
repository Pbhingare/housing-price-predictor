# 🏠 Housing Price Predictor

A machine learning web app that predicts house 
prices using 13 different ML models.

## 🤖 Models Used
- Linear Regression, Ridge, Lasso, ElasticNet
- Random Forest, XGBoost, LightGBM
- ANN, SVM, KNN and more!

## 🛠️ Tech Stack
- Python, Flask
- Scikit-learn, XGBoost, LightGBM
- HTML, CSS

## 🚀 How to Run
pip install -r requirements.txt
python model.py
python app.py
